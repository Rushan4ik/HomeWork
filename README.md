## Как работает:
Для того чтобы все операции выполнялись за О(1), нужно использовать дополнительную память.
Стэк реализован через тип данных **список(list)**.
Метод **push** реализовал через метод **append**.(Его сложность О(1))
Метод **pop** реализовал через метод **pop**.(Его сложность О(1))
Для метода **top** достаточно возвращать последний элемент списка(items[-1], сложность О(1))
Для метода **get_min** я завел дополнительный стэк.(завел список, в который элемент добавляется только тогда, когда он меньше чем последний элемент списка)
